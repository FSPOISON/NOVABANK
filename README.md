# NovaBank Application

Laboratorio 1 de la materia Arquitectura de Software - Universidad de Antioquia.

Implementation of a Simple Spring Boot App for NovaBank including integration with GitHub Actions, SonarCloud, and Docker.

### Folders Structure
In the folder `novabank` is located the main code of the app.
In the folder `novabank/src/test` is located the unit tests.

### How to install it
Execute:
```shell
cd novabank
./mvnw spring-boot:run
